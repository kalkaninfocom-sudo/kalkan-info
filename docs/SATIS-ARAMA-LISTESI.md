> Sıralama: açıklık skoru (çok yorum + web yok + IG yok = en kolay satış). Yukarıdan aşağı ara.
> Kaynak: data/restoranlar.json (telefon/yorum) + demo/<slug>/ + satis-demo/teklif-data.json.

**Akış:** demo linkini aç → ara/WhatsApp → "evet" gelince `node scripts/agency/deploy-venue-site.mjs <slug>` ile gerçek domaine paketle. Fiyat sorulursa önce demo ile ikna, sonra 10-15k TL/ay paket.
**İç satış paneli:** kalkaninfo.com/satis-demo/teklif/ (ara → Teklifi Aç / Linki Kopyala).
